# AI-TREAD // System Architecture Audit Report

This document reports the findings of a comprehensive code audit of the AI-TREAD Tyre Quality Analyzer codebase, completed on May 29, 2026. The objective was to identify simulated, mock, or hardcoded predictions vs real machine learning computations.

---

## 🔍 Core Findings Summary

Our audit confirms that the dashboard currently displays **simulated computer vision heuristics and randomized presenter overrides** rather than true forward inference predictions from a deep learning classifier. 

Every key diagnostic metric displayed on the dashboard—AI Confidence, Tread Depth, Safety Index, and YOLOv8 Bounding Boxes—is simulated or computed via heuristics in `processor.py`.

---

## 📊 Metric Audit & Source Mapping

### 1. Metric: AI Confidence Score
* **Source File:** [`processor.py`](file:///c:/Users/navee/OneDrive/Desktop/ML2/processor.py)
* **Calculation Function:** `run_ai_classification`
* **Audit Status:** ❌ **SIMULATED**
* **Technical Details:** 
  * If the filename matches standard keywords (e.g. "good", "worn", "damaged"), the confidence is set to presets (e.g., `96.8`, `93.4`, `97.5`).
  * If no keywords match, the confidence is computed using simple linear clipping equations over the mean Canny edge density:
    `confidence = float(np.clip(90.0 + (32.0 - smooth_md) * 2.0, 88.0, 96.5))` (lines 213, 219, 226, 234, 246, 251).
  * In override modes, it generates pseudo-random float percentages in a preset range:
    `confidence = round(float(np.random.uniform(93.5, 98.9)), 1)` (lines 268, 272, 276).

## 🛠️ Refactoring & Resolution Plan

To transform this mock exhibition app into a **true deep-learning analyzer**, we will:
1. **Unify the Backbone**: Initialize PyTorch and load your trained weights `best_tyre_model.pth` directly into memory upon the first prediction call.
2. **Execute Real Forward Passes**: Preprocess input images using standard ImageNet transforms, run a PyTorch forward pass, and compute direct softmax probabilities.
3. **Calculate Real Bounding Boxes**: Replace the mocked coordinates with real bounding box coordinates generated by actual OpenCV contour analyses of the largest circular structure (the tyre).
4. **Console Log Outputs**: Print the exact predicted class, raw softmax scores, and confidence to the system console for every classification event.
5. **Display Real Softmax Vectors**: Print the raw prediction vector dynamically on the Streamlit dashboard as requested.
